## 1. 部署到 GitHub Pages（約 3 分鐘）

1. 打開 https://github.com/hengmagnet/wanderquest-2
2. 點 **Add file → Upload files**，把這個 ZIP 裡的 **`index.html`** 拖進去（會取代舊的同名檔案）。
3. 下方按 **Commit changes**。
4. 確認 **Settings → Pages**：Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾 `/(root)`。
5. 等 1–2 分鐘後打開 https://hengmagnet.github.io/wanderquest-2/
6. 若還是舊版，按 **Ctrl + Shift + R**（Mac：**Cmd + Shift + R**）。新版第一個畫面是「Choose Your Language / 選擇語言」，下方顯示 `v3.5.0-playtest`。

> 只有 `index.html` 是遊戲必要檔案；`source/` 是團隊後續修改用的原始碼與測試。
> 目前 GitHub 上仍是最早的舊版（拼圖判定有錯），一定要上傳這個新檔案。

## 2. 遊戲流程

選擇語言 → **註冊頁**（姓名、國籍皆必填）→ **貓空歷史對話框**（Mossy 一句一句介紹，共 8 段，必須點完才能進入）→ 約 60 秒互動教學 → 記憶菌絲地圖。

- **每次打開遊戲，第一個畫面都是雙語的「Choose Your Language / 選擇語言」。** 已註冊的玩家選完語言後會看到「歡迎回來，〇〇」，可繼續冒險或註冊新玩家；同一分頁重新整理不會重複詢問。
- **關於註冊資料：** 因為遊戲放在 GitHub Pages、沒有伺服器，姓名與國籍只存在玩家自己的瀏覽器裡，**團隊看不到**，也沒有密碼。若需要收集，請在 Google 表單中加入「姓名」「國籍」「遊玩代碼」題目（結局會顯示玩家的匿名遊玩代碼，方便對照）。選單裡的「匯出遊玩紀錄」也會包含姓名與國籍。

- **地圖上每個地點都可以點**，會先跳出該地點的歷史簡介卡，再決定是否進入。
- 完成貓空站後，**兩條路線同時開放**，各自依序前進：
  - 路線 A：貓空站 → 小天空步道、壺穴步道 → 茶展中心步道 → 健康步道 → 茶研發推廣中心（路線 A 結局）
  - 路線 B：貓空站 → 樟樹步道 → 登高步道 → 杏花林 → 樟湖步道 → 貓空越嶺步道（路線 B 結局）
- 11 個地點全部完成 → 最終結局。**回饋表單只在最終結局出現**，並附上「我們非常需要你的回饋」的邀請文字（地圖、選單、路線 A／B 結局都不再顯示）。
- 「👇 下一步」跳動提示會標出下一個該點的地方（只指方向，不給答案）。
- 畫面上方的**旅程時間軸**顯示兩條路線所有地點：已完成（✓）、你在這裡、尚未解鎖（🔒），點任一站可看簡介。
- 每個機關都有三層提示、答錯會給具體回饋、可無限重試；進度自動保存，切換中英文不會遺失。

## 2.5 後台（Google 試算表）

ZIP 裡的 `backend/` 資料夾有後台程式 `Code.gs` 和 **`設定說明_SETUP.md`**（約 10 分鐘）。設定好後，玩家的註冊、回訪、完成每一站、使用提示、完成路線、全部破關都會自動寫進你的 Google 試算表（可下載成 Excel），**包含每一站的實際遊玩分鐘**（只算畫面開著、該站尚未解開的時間；尚未解開的站顯示「進行中」）。`backend/後台範例_sample.xlsx` 是用**模擬資料**經過真正的 `Code.gs` 產生的範例，讓你先看看長相。

- 預設 **不上傳**（`SHEET_ENDPOINT` 是空的）。填入網址後才會開始傳送，註冊頁的隱私說明也會自動改為照實告知。
- 已測試：用本機模擬伺服器跑 3 輪完整通關，遊戲送出 59 筆資料，全部被 `Code.gs`（在模擬的 Google 試算表環境中執行）正確寫入兩張工作表；未設定網址時沒有任何網路傳輸。
- 計時已在瀏覽器中驗證：在站內 12 秒記 12 秒；切到別的 App 16 秒不計；在地圖上 11 秒不計入任何一站（`check_timing.mjs`）。
- **未測試**：真正的 Google Apps Script 部署（需要你的 Google 帳號）。設定完請照說明的步驟 4 用手機測一次。
